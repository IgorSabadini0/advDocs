# AdvDocs

This project was created to make finding client documents and folders easier.

## 📋 Overview

Office System is a document management solution designed to streamline the process of organizing, searching, and accessing client documents and folders. The system provides an intuitive interface for efficient document retrieval and management.

## 🏗️ Project Structure

```
AdvDocs-/
├── backend/          # Backend server and API
├── frontend/         # Frontend user interface
├── LICENSE           # MIT License
├── .gitignore        # Git ignore rules
└── README.md         # Project documentation
```

## 🚀 Features

- **Document Organization**: Structured system for managing client documents
- **Easy Search**: Quick and efficient document retrieval
- **Client Management**: Organize documents by client
- **Folder Structure**: Hierarchical folder organization
- **User-Friendly Interface**: Intuitive design for easy navigation

## 🛠️ Technology Stack

- **Language**: JavaScript, Node.js, API, MySQL
- **Architecture**: Full-stack application with separate frontend and backend
- **License**: MIT
